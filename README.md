# Econ-Nexus · 论文整理

个人论文阅读与学习资料库，使用本地 HTML、CSS 和 JavaScript。

## 打开

下载仓库后，直接用浏览器打开 `index.html`。无需安装依赖，页面资源均保存在本地。

## 页面

- 主页：原始目录、整理目录两个入口。
- 原始目录：按整理日期呈现资料，当前为空。
- 整理目录：为今后按主题积累预留，当前为空。
- 资料阅读模板：先综述，再按文章脉络展开；当前没有收录资料或示例。

牛皮纸风格、约一秒的页面过渡，支持小屏单列布局与减少动态效果偏好。

## 后续更新

资料记录位于 `assets/library.js`；样式位于 `assets/style.css`。
浏览器不会自动写入本地资料文件；新增资料需要更新项目文件。
